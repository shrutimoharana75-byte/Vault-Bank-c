# 🏦 Simple Banking System (C Language)

A clean and beginner-friendly **Banking System Project** built using
**pure C language**. This project is perfect for students who want to
understand file handling, structures, basic authentication, and
menu-driven programs.

## 📌 Features

-   ➕ **Create New Account**
-   🔐 **Login Using Account Number & PIN**
-   💰 **Deposit Amount**
-   💸 **Withdraw Amount**
-   🧾 **Check Balance**
-   💾 **Data Stored Permanently** using text files
-   🧱 **Simple Code Structure** (Easy to modify & understand)

------------------------------------------------------------------------

## 📁 Project Structure

    📂 Banking-System-C
     ├── bank_simple.c       # Main source file
     ├── accounts.txt        # Stores account info
     └── transactions.txt    # Stores transaction logs

------------------------------------------------------------------------

## 🚀 How to Run the Program

### 1️⃣ Compile the Code

    gcc bank_simple.c -o bank

### 2️⃣ Run the Program

    ./bank

------------------------------------------------------------------------

## 👤 Sample Workflow

1.  Run the program
2.  Select **1. Create Account**
3.  Enter Name, PIN, Initial Deposit
4.  Use the generated Account Number to **Login**
5.  Deposit/Withdraw/Check Balance as needed
